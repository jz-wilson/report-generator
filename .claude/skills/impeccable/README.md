# Impeccable (markdown only copy)

Copy of the [Impeccable](https://impeccable.style/) design skill, version 4.8.1, from <https://github.com/pbakaus/impeccable>. Licensed Apache 2.0 (see `LICENSE` and `NOTICE.md`).

This copy holds only markdown: `SKILL.md` and `reference/*.md`. It leaves out the CLI, scripts, and hooks, so nothing needs to be installed or run.

## Use it

Open this repo in Claude Code and run commands such as:

- `/impeccable polish <file>`
- `/impeccable critique <file>`
- `/impeccable typeset <file>`

## Limits

Commands that call the `scripts/impeccable` helper (`live`, the design hook, and the detector) will not work here. The writing and review commands work as plain instructions.
